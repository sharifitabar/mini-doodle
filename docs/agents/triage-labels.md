# Triage Labels

The skills use five standard triage roles.
This repository uses the same label strings in GitHub:

- `needs-triage` — Maintainer needs to evaluate this issue
- `needs-info` — The reporter must supply more information
- `ready-for-agent` — Fully specified, ready for an AFK agent
- `ready-for-human` — Requires human implementation
- `wontfix` — No action will be taken

When a skill mentions a role (for example "apply the AFK-ready triage label"), use the label with the same
name.
